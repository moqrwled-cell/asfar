# 🛒 سوبر ماركت مقداد (Meqdad Supermarket POS & Management System)

نظام إدارة ومبيعات وديون ومصاريف وصندوق سحابي متكامل فائق السرعة، مصمم ومبرمج بأعلى معايير تجربة المستخدم وتصميم **Apple Design** واللغة العربية، ومربوط بقاعدة بيانات سحابية **Supabase (PostgreSQL)** مع دعم كامل لتقنية **Offline-First**.

---

## 🌟 الميزات الرئيسية

### 1. الدفتر اليومي ونقاط البيع السريعة (POS)
- نظام إدخال سريع يعتمد على **أقسام السوبر ماركت الشاملة** (ألبان، معلبات، مشروبات، تسالي، مخبوزات، منظفات، سجائر، مجمدات، إلخ) بدون الحاجة لإدخال آلاف الأصناف يدوياً أو الباركود المعقد.
- عدادات كميات تفاعلية سهلة اللمس `+` و `-`.
- إكمال واقتراح تلقائي ذكي لأسماء الزبائن المسجلين.
- مرونة كاملة في طرق الدفع: كاش، بنك/فيزا، محفظة إلكترونية، جوال بي.
- **نظام السداد الجزئي المرن:** عند دفع جزء من الحساب، يتاح خياران محددان:
  - `نقل المتبقي إلى دفتر الديون`.
  - `خصم ومسامحة في الباقي`.

### 2. محرك الترحيل التلقائي للديون (Daily-to-Debt Engine)
- فحص دوري عند فتح التطبيق وبداية كل يوم جديد للطلبات السابقة غير المدفوعة.
- ترحيل آلي للمتبقي إلى حساب الزبون في دفتر الديون مع تفصيل الأصناف والتواريخ والملاحظات ووسمها لمنع التكرار نهائياً.
- زر نقل فوري يدوي للديون من بطاقة الطلب اليومي بضغطة واحدة.

### 3. دفتر الديون وحسابات الزبائن (Customer Debts Ledger)
- كشف حساب تفصيلي لكل زبون (تاريخ المشتريات، الدفعات النقدية المسددة، الخصومات).
- تسجيل دفعات نقدية مع إمكانية إضافة خصم مسامحة تشجيعي.
- **مشاركة كشف الحساب عبر الواتساب (WhatsApp):** رسالة منسقة بضغطة زر واحدة موجهة للزبون مع كافة تفاصيل الرصيد المتبقي.

### 4. إدارة الصندوق والدرج النقدي (Cash Drawer)
- حساب النقدية الحية المتوقعة في الدرج لحظة بلحظة:
  $$\text{صافي كاش الدرج} = (\text{كاش المبيعات} + \text{كاش سداد الديون} + \text{الإيرادات اليدوية}) - \text{المصروفات النقدية}$$
- فصل المبالغ غير النقدية (البنكية والإلكترونية) لمنع أي عجز أو التباس أثناء استلام وتسليم الورديات.
- حاسبة جرد العملات الورقية والفكة للتحقق من مطابقة الصندوق بنسبة 100%.

### 5. المصاريف اليومية
- تصنيف نفقات السوبر ماركت (بضاعة كاش، فواتير، كهرباء ومياه، رواتب وعمال، إيجار، صيانة، متفرقات).
- ربط كل مصروف باسم العامل وتاريخه ووقته.

### 6. التقارير المالية والأرباح
- تقرير تقفيل اليومية الشامل لطباعته أو أرشفته.
- التقرير الشهري للأرباح مع حساب هامش الربح التجاري التقديري ونسبة الربحية لكل قسم.
- أكثر الأقسام مبيعاً وأكثر الزبائن تعاملاً.
- التقارير علنية ومتاحة مباشرة لجميع المدراء بدون تعقيد أو رموز سرية إضافية.

### 7. إعدادات الواجهة (Apple Design & UI Controls)
- التحكم بحجم الخط (صغير - متوسط - كبير).
- التحكم بكثافة الخانات والمسافات (مضغوط - عادي - واسع).
- تصدير واستيراد نسخ احتياطية كاملة بصيغة JSON.

## 🛠️ البنية التقنية (Tech Stack)

- **Frontend:** React 19, TypeScript, Vite
- **Styling:** Tailwind CSS, Apple SF/Alexandria Typography, Frosted Glass Backdrop-blur
- **Database:** Supabase (PostgreSQL with RLS & Realtime Enabled)
- **State Management:** Reactive Local-First Cache + Realtime Pub/Sub
